# Artifact5

A minimal Node.js HTTP server built with the [Express.js](https://expressjs.com/) web framework. It is a tutorial-style, single-file server (`server.js`) that exposes two plain-text `GET` endpoints — one returning `Hello world` and one returning `Good evening`.

## Prerequisites

- **Node.js >= 18** — required by Express 5.
- **npm** — the Node.js package manager, bundled with Node.js.

## Installation

Install the project dependencies:

```bash
npm install
```

This installs Express (the sole runtime dependency) into `node_modules/`. The `node_modules/` directory is git-ignored and is regenerated by `npm install`, so it is never committed.

## Running the Server

Start the server:

```bash
npm start
```

The `start` script runs `node server.js`. By default the server listens on `http://localhost:3000`. The port can be overridden with the `PORT` environment variable — the server binds `process.env.PORT || 3000`.

## Endpoints

| Method | Path | Response |
|--------|------|----------|
| `GET` | `/` | `Hello world` |
| `GET` | `/good-evening` | `Good evening` |

Both responses are returned with HTTP `200` as plain text. The `/` route preserves the original "Hello world" tutorial behavior, now served through Express.

## Example Requests

With the server running, the endpoints can be exercised with `curl`:

```bash
curl http://localhost:3000/             # -> Hello world
curl http://localhost:3000/good-evening # -> Good evening
```
